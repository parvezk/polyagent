## Startup description (681/800)

I hand work to coding agents from several companies every day. Jules also scans my repos and starts tasks on its own. As I write this, every recent Jules session in two of my repos is stopped at "Needs clarification", waiting for me. Claude, Cursor and Gemini each keep their own list of runs, so I find blocked work late and answer it one tool at a time.

PolyAgent puts every agent run in one place. Today it sends tasks to Claude, Jules, Cursor and Gemini, shows their status in one list, and sends follow-ups. Next I am building one queue of agent questions and finished work. Each item says what the agent changed and why, so I can answer, approve or stop it in a few minutes.
